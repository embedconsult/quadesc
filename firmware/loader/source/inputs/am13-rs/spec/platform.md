# AM13 LED support 0.1

This implements the chip portion of accepted am13-led-target/0.1.0, not a full PAC/HAL. Device take is one-shot per boot and yields disjoint clock, pad/GPIO, UC4 and SysTick owners. Handles remain !Send/!Sync and move into thread executor tasks; only the global time driver shares critical-section-protected RAM with SysTick. No shared MMIO object escapes and no peripheral IRQ accesses GPIO/UART.

Clock selection: factory 32 MHz SYSOSC, USEHSCLK=0, MCLKDIVCFG=7; semi-domain division is bypassed on SYSOSC. UC4 CLKSEL=8, CLKDIV=0, 16x oversampling. Clocks are nominal configuration evidence, never measured frequency. No HSCLK, STOP/STANDBY, PLL or runtime frequency changes. UART config is separate from board-selected pad mux; peripheral enabled only after board mux. Errors precede received data. Each nonblocking call has finite MMIO operations. Async read/write retry using Embassy Timer every 100 us; each successful write returns its admitted prefix (cancellation never hides admitted bytes). Flush waits for tracked TX completion through raw EOT, including the final stop bit, independently of RX. An untouched transmitter is already complete. Admission is limited to one outstanding byte; see [TX completion](uart-completion.md) for races and bounds. This is a foreground adapter, not DMA/IRQ transport throughput qualification.

Driver: embassy-time-driver 0.2.2, embassy-time 0.5.1 at 10000 Hz; embassy-executor 0.9.1. Fixed 16 TaskRef/deadline slots; one earliest outstanding deadline per task, including cancelled timers. It is valid to spuriously wake a cancelled timer's task. Table entry removed before wake, and later timers re-register after an early wake. Driver now is zero before start, increments saturating u64 under critical section, never resets during actor reset. Timestamps use checked ticks*100 for microseconds. Startup consumes the SysTick owner and programs reload 3199; only one handler calls tick. Deadline capacity is a task-count integration budget; overflow latches a fault and halts via fixed panic. No arbitrary waker clone/drop, queue allocation or retry loop. Only Embassy task wakers supported (executor validates them).

Interrupt masking longer than 100 us can lose SysTick events; software cannot reconstruct multiple missed wraps from one pending bit. This is a measured integration constraint, not a wall-clock accuracy guarantee. No IRQ performs application actions. Tick extracts a bounded wake array under CS, then wakes outside it. Runtime allocator/fault-path qualification remains T36/full-image T13.
