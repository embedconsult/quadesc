# Conditional target UART SAVE composition

The generated `led-owner` retains the only calibration Owner and one `ProfileSlot`. Startup classifies both reserved MAIN slots only after healthy ECC-aware reads and checked mapping; the same recovered config primes LED output and service. The backend pump takes fixed commands from the service, preserves full headers and original absolute deadlines, and reports only observed completion. A reset requests quiesce and retains the flash handle; it does not mint a lease. UART receipt is separate from durable terminal resolution.

No lease or inventory history is available on this server. Unknown history means zero authority. Target startup therefore remains read-only and SAVE reports denial until the fixture provides a durable lease/intent/receipt store and the controller admission predicates. No target operation is authorized by this spec.
