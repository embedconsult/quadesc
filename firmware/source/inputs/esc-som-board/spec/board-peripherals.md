# Board resource profile

Call `esc_som_board::peripherals::initialize(device, uart_baud)` only in a new characterization firmware. Existing `esc_som_board::initialize` still constructs the LED/UART/flash profile and leaves CAN, ADC, SPI, I²C and PWM unused. Application code receives the returned resource struct once; it moves each owner to its platform service. Driver calls do not encode sweep recipes, XCP messages, sample policy or actor state.

`pins::PWM_ROUTES` gives each current v3 motor output as `(pin, mux, MCPWM module, output selector)`. MCPWM0–3 share one timer period within each module. Outputs are forced low before their pads are remuxed. `drivers` owns PB10 DRV_ENABLE, PB11 INL_ENABLE, four CS outputs and four active-low fault inputs. Both enables start low and CS lines start high. `drivers.transfer/read_register/write_register` use UC3 PC6/PC4/PC2. Gate enable is always an explicit application call.

`analog` owns all 30 v3 SoM analog assignments, with names such as `PA3/A0_4`. `scan_all()` sequentially returns a raw result or explicit error for each input. These are not simultaneous readings or converted voltage/current/temperature values. Historical mainboard documents list 29 logical analog nets (12 currents, 12 phase voltages, four temperatures, battery). The current v3 export lists 30 assigned SoM ADC pads; the saved SoM schematic identifies PA28 as an `AN` connector/test net, which may explain one extra pad. Because those historical net allocations conflict with v3, this profile does not guess a 29-to-30 semantic mapping. Check assembled board/netlist before attaching units and coefficients.

`i2c` owns UC2 PA22 SDA and PA23 SCL. `can_termination` owns PB9 pin 68 and starts disabled (low). The saved switch circuit connects CAN_TERM to TS5A3166 U3 C2/IN. [TI's function table](https://www.ti.com/lit/ds/symlink/ts5a3166.pdf) specifies low=open, high=closed. The historical saved schematic names **PC0 pin 97** on this net, whereas current v3 selects **PB9 pin 68**. PB9 is the firmware pin authority, and physical continuity from PB9 to U3 C2 must be checked on the actual assembled revision. `requested_enabled()` is only the requested GPIO state; it is not a resistance measurement.

`mcan0` stays unconfigured in the returned resources. The application may choose the termination setting first, then call `mcan0.configure(125_000 | 250_000 | 500_000)`. MCAN TX is PA12 pin 73 mux 10; RX is PA11 pin 72 mux 10. CANCLK comes from the 25 MHz SoM crystal on PC16/PC17 according to the saved SoM clock reference and v3 X1/X2 assignments; MCLK/UART remain 32 MHz. Validate oscillator frequency, bit timing, transceiver traffic, bus-off and termination resistance on the fixture before reporting hardware success.
