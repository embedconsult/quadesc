# Target ProfileSlot boundary r2

A target adapter may attach the existing `ProfileSlot` once before the generated Owner starts. The slot owns the portable service/Broker; the Owner alone captures active scalars. The target backend pump owns no mutable Owner reference, takes one service command at a time and completes by exact full header. Terminal UART SAVE status follows the service outcome after ownership settlement. Logical Reset fences/quiesces pending backend work and does not reconstruct the slot or mint epochs.
