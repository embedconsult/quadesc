## Reading and printing

The printable versions combine each manual into one page. Use your browser's print command to print or save a PDF. Navigation, search and bundled diagrams work from this site's files without loading remote assets. Links to manufacturer and protocol references open their external websites.

## Schematic downloads

The schematic PDF links open GitHub release assets generated from the latest revised KiCad schematics on `main`. GitHub Actions updates the rolling **Schematic PDFs** prerelease after changes merge; pull requests provide downloadable preview artifacts.
